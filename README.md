# அருள்மிகு ஸ்ரீ மாணிக்கேஸ்வரர் திருக்கோயில், பரவாக்கரை
## ஶ்ரீ மரகதவல்லி அம்பாள் சமேத ஸ்ரீ மாணிக்கேஸ்வரர் பக்தி இணையதளம்

> **“நமச்சிவாய வாழ்க! நாதன் தாள் வாழ்க!”**

இவ்விணையதளம் பி.டெக் (B.Tech) பயிலும் மாணவரும், சிவபக்தருமான ஒருவரால் பரவாக்கரை அருள்மிகு ஸ்ரீ மாணிக்கேஸ்வரர் திருக்கோயிலின் மகா கும்பாபிஷேக திருநாளை முன்னிட்டு அன்புடன் படைக்கப்பட்ட டிஜிட்டல் பக்தி அர்ப்பணிப்பாகும்.

---

## 🌟 முதன்மை சிறப்பம்சங்கள் (Features)

1. **முழுமையான தமிழ் இடைமுகம் (100% Tamil UI):**
   - தமிழ் மரபு, சைவ பக்தி மற்றும் திருமுறை சிறப்புகளைப் பிரதிபலிக்கும் எளிய, நயமான வடிவம்.
   - Noto Sans Tamil & Noto Serif Tamil கணினி எழுத்துருக்கள் மூலம் இயல்பான வாசிப்பு அனுபவம்.

2. **கும்பாபிஷேக எண்ணிப்பு கணிப்பான் (Live Kumbhabhishekam Countdown):**
   - 06 செப்டம்பர் 2026 கும்பாபிஷேக திருநாளை நோக்கிய நேரடி கணக்கீடு.
   - விழா முடிந்த பின் தானாக நிறைவுச் செய்தியைக் காட்டும் வடிவமைப்பு.

3. **சிவபுராணம் & திருவாசகம் வாசிப்பு அனுபவம் (Thiruvasagam Reader):**
   - மாணிக்கவாசகர் அருளிய சிவபுராணம், திருவெம்பாவை, திருப்பள்ளியெழுச்சி உள்ளிட்ட 50 பாடல்கள் மற்றும் விரிவான தமிழ் பொருள்.
   - எழுத்து அளவு கட்டுப்பாடு (+ / - / Reset).
   - நிரந்தர அமைதியான இரவு வாசிப்பு முறை (Permanent Dark Reader).
   - பாடல்களை நகலெடுக்கும் வசதி.

4. **சிவ வழிபாட்டின் சிறப்பு நாட்கள் (Special Shiva Worship Days):**
   - மகா சிவராத்திரி, பிரதோஷம், மாத சிவராத்திரி, திருவாதிரை, கார்த்திகை தீபம், சோமவாரம், அன்னாபிஷேகம், மார்கழி நோன்பு குறித்த 2026 ஆன்மிக வழிகாட்டி.

5. **திருக்கோயில் விவரங்கள் & வரலாறு (Authentic Heritage):**
   - உண்மைக்கு புறம்பான வரலாற்றுச் செய்திகளைத் தவிர்த்து, உள்ளூர் சைவ மரபின் அடிப்படையில் எழுதப்பட்ட தகவல்கள் (தஞ்சாவூர் பரம்பரை சான்றுகளுடன்).
   - மூலவர் ஸ்ரீ மாணிக்கேஸ்வரர் மற்றும் ஸ்ரீ மரகதவல்லி அம்பாள் சன்னதி சிறப்புகள்.

6. **புகைப்படத் தொகுப்பு & வரைபடம் (Gallery & Location):**
   - அதிகாரப்பூர்வ புகைப்படங்கள் விரைவில் சேர்க்கப்படும் வகையிலான காட்சியகம் (Lightbox View).
   - Google Maps-ல் வழிகாட்டியைப் பெற நேரடி இணைப்பு (`https://maps.google.com/?q=Paravakkarai+Sivan+Temple`).

## 🛠 தொழில்நுட்பக் கட்டமைப்பு (Tech Stack)

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS (Devotional Shaft Color Theme)
- **Icons:** Lucide React
- **Typography:** Noto Sans Tamil & Noto Serif Tamil (Google Fonts)
- **Architecture:** 100% Static & Lightweight, PWA-Ready

## ⚙️ தகவல்களை புதுப்பிப்பது எப்படி? (Data Configuration)

கோயிலின் தகவல்கள், கும்பாபிஷேக நாள், படங்கள் அல்லது கூகுள் வரைபட இணைப்பை மாற்ற விரும்புபவர்கள் **`src/data/templeData.js`** என்ற கோப்பில் உள்ள தரவுகளை மட்டும் மாற்றினால் போதும். React குறியீடுகளை மாற்றத் தேவையில்லை.
